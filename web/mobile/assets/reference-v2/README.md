# Reference-matched application illustrations

These are local application assets, generated with the built-in imagegen tool using the user's supplied NeuroCompanion reference as style guidance. They replace the earlier simplified clipboard/heart/brain drawings. The reference infographic itself is not used as the application UI.

Final files in this directory:

| File | Delivered asset | Encoded size |
| --- | --- | --- |
| `plan.webp` | 512 × 512 lavender 3D clipboard with blue/periwinkle ribbon, alpha | 32,796 bytes |
| `support.webp` | 512 × 512 peach heart and lavender hands, alpha | 30,346 bytes |
| `brain.webp` | 512 × 512 luminous lavender brain, alpha | 39,354 bytes |

Original generated PNGs remain preserved in the image tool's output directory. The delivered WebP variants were downsampled/encoded for application use without changing the illustration composition. No external asset service or live image-generation call is used by the app. Empty alt text and reserved width/height mark these illustrations as decorative and avoid layout shifts.

## Prompt set

Common instruction: “Create a new isolated illustration asset. Input is ONLY a style reference; do not edit or reproduce the infographic.” Transparent output was requested in the image tool.

**Plan:** A premium small 3D lavender clipboard checklist illustration, closely match the clipboard illustration in the upper-right of the My Plan phone in the reference. Rounded lilac plastic clipboard, ivory recessed paper, three lavender bullet dots and embossed horizontal checklist lines WITHOUT any words, two cute violet binder rings along the top, slight clockwise tilt, soft studio lighting, gentle translucent blue and periwinkle ribbon curving behind the bottom-right. Full object within frame, centered, occupies 85% of square. No text, no UI, no phone, no background. Transparent alpha. Soft refined 3D product-icon rendering exactly in the pastel visual family of the reference, not flat vector.

**Support:** A premium small 3D care illustration closely match the heart-in-hands illustration in the upper-right of the Support phone in the reference. Two softly sculpted lavender/violet hands cupping a floating warm peach heart with a thin white outline heart embossed in its center, fingers gently open upward, softly rounded organic forms, soft studio lighting and subtle material shading, a restrained pale blue/periwinkle flowing ribbon behind lower right. Full object within frame, centered, occupies 85% square. No text, no UI, no phone, no background. True transparent alpha. Delicate pastel 3D product-icon style matching the reference, not flat vector.

**Brain:** A delicate luminous brain outline illustration for the blue hero card, match the thin neon lavender brain shown at the upper-right of the Home phone card in the reference. Recognizable anatomically stylized brain viewed from front with subtle 3/4 volume, fine glowing lavender-white continuous neural fold contours, transparent interior, delicate purple halo confined closely around the brain, tasteful small translucent holographic 3D appearance. Full brain centered occupies 80% square, no solid backing. No text, no UI, no phone, no background. Genuine transparent alpha; image must composite elegantly on royal blue. Not a thick cartoon icon, not a bulb, not two simple lobes.
