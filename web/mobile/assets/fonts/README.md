# Local Inter font

`InterVariable.woff2` is the unmodified Inter variable font from the official [Inter v4.1 source](https://github.com/rsms/inter/blob/v4.1/docs/font-files/InterVariable.woff2). Its original [SIL Open Font License](https://github.com/rsms/inter/blob/v4.1/LICENSE.txt) is included as `Inter-LICENSE.txt`.

The mobile application serves this font locally as the CSS family `Neuro Inter`, with swap fallback. No font CDN or third-party runtime request is necessary. The clinical dashboard does not load this font or these mobile styles.
